# 监控大屏展示维度说明

根据当前 QMT 策略（`backend/QMT.py`）写入的 `strategy_state.json` 及前端展示，整理如下维度。

---

## 1. 连接状态 (connection)

| 字段 | 说明 | 来源 |
|------|------|------|
| connected | 是否已连接 QMT | 策略运行时为 true |
| lastHeartbeat | 最后心跳时间 | 每次 write_state_to_dashboard 时的当前时间 |
| accountId | 资金账号（脱敏后四位） | ACCOUNT_ID |
| qmtHost | 交易端标识 | 固定 "QMT" |

**前端组件**：`ConnectionStatus`

---

## 2. 账户概览 (account)

| 字段 | 说明 | 来源 |
|------|------|------|
| totalAsset | 总资产 | get_account_info → m_dBalance |
| available | 可用资金 | get_account_info → m_dAvailable |
| todayPnl | 当日盈亏 | get_account_info → m_dPositionProfit |
| todayPnlRatio | 当日盈亏比例(%) | todayPnl / totalAsset × 100 |
| dailyLossLimitHit | 是否触发单日亏 2% 限制 | todayPnl/totalAsset ≤ -0.02 |

**前端组件**：`AccountOverview`

---

## 3. 大盘环境 (market_env)

| 字段 | 说明 | 来源 |
|------|------|------|
| signal | 六档信号 | get_env：RED / YELLOW / STRONG_YELLOW / GREEN / STRONG_GREEN / SUPER_GREEN |
| shIndex | 上证指数收盘 | 000001.SH 日 K 最后一根 close |
| shMa20 | 上证 20 日均线 | 近 20 日 close 均值 |
| shTodayReturn | 上证当日涨跌幅(%) | (今收/昨收-1)×100 |
| dropDaysIn10 | 近 10 日下跌天数 | 近 10 日 rise≤-1 的天数 |

**前端组件**：`MarketEnv`（展示信号、指数、MA20、今日涨跌、近 10 日下跌天数）

---

## 4. 市场情绪 (market_sentiment)

| 字段 | 说明 | 来源 |
|------|------|------|
| label | 情绪标签 | get_market_sentiment：情绪高涨 / 情绪正常 / 情绪冰点 |
| avgChange | 昨日涨停股今日平均涨跌幅(%) | 以昨日涨幅≥9.5% 的股票为样本，计算其今日平均涨跌 |

**逻辑简述**：策略用「昨日涨停股今日平均涨跌」划分三档，并在此基础上调整仓位（情绪高/中/低对应不同仓位比例）。

**前端组件**：`MarketSentiment`

---

## 5. 下次节奏 (schedule)

| 字段 | 说明 | 来源 |
|------|------|------|
| now | 当前时间 | datetime.now() |
| nextBuy | 下次买入时间 | 今日 BUY_HOUR:BUY_MINUTE（如 14:50） |
| nextSell | 下次卖出时段 | 明日 SELL_START～SELL_END（如 9:30 - 10:30） |
| isWeekend | 是否周末 | now.weekday() >= 5 |

**前端组件**：`NextSchedule`

---

## 6. 策略参数 (strategy_params)

| 字段 | 说明 | 来源（QMT 常量） |
|------|------|------------------|
| maxPositionGreen | 绿灯仓位比例 | MAX_POSITION_GREEN |
| maxPositionYellow | 黄灯仓位比例 | MAX_POSITION_YELLOW |
| maxStocks | 最大持股数（绿灯） | MAX_STOCKS_GREEN |
| minBuyVolume | 最小买入股数 | MIN_BUY_VOLUME |
| maxDailyLossRatio | 单日亏损停手比例 | MAX_DAILY_LOSS_RATIO |
| buyTime | 买入时间 | BUY_HOUR:BUY_MINUTE |
| sellStart / sellEnd | 卖出时段 | SELL_START / SELL_END |
| takeProfit | 止盈阈值(%) | TAKE_PROFIT_1 |
| stopLoss | 止损描述 | 文案如「成本-1.5×ATR(14)」 |
| minPrice / maxPrice | 选股价格范围 | MIN_PRICE, MAX_PRICE |
| minRise / maxRise | 选股涨跌幅范围(%) | MIN_RISE, MAX_RISE |
| positionTiers | 仓位梯度列表 | 六档信号 + 每档仓位与最多持股数 |

**前端组件**：`StrategyParams`

---

## 7. 持仓 (holdings)

| 字段 | 说明 | 来源 |
|------|------|------|
| code | 股票代码 | HOLD_CODES key |
| name | 股票名称 | get_stock_data → name 或 get_instrumentdetail |
| volume | 持仓数量 | HOLD_CODES[code].volume |
| costPrice | 成本价 | HOLD_CODES[code].cost |
| currentPrice | 当前价 | get_stock_data → price，无数据时用 cost |
| pnlRatio | 盈亏比例(%) | (currentPrice - costPrice) / costPrice × 100 |

**前端组件**：`HoldingsTable`

---

## 8. 数据更新时间 (updatedAt)

所有接口在存在状态文件时都会带上 `updatedAt`，值为 `strategy_state.json` 中的 `updated_at`（策略最后一次写入时间）。  
前端在页头展示：「数据有效时间截止到：YYYY-MM-DD HH:mm:ss」。

---

## 后端 API 与前端对应关系

| API | 说明 | 前端使用 |
|-----|------|----------|
| GET /api/state_meta | 仅返回 updatedAt | 页头「数据有效时间」 |
| GET /api/connection | 连接状态 | ConnectionStatus |
| GET /api/account | 账户概览 | AccountOverview |
| GET /api/market_env | 大盘环境 | MarketEnv |
| GET /api/market_sentiment | 市场情绪 | MarketSentiment |
| GET /api/schedule | 下次节奏 | NextSchedule |
| GET /api/strategy_params | 策略参数 | StrategyParams |
| GET /api/holdings | 持仓列表 | HoldingsTable |

---

## 状态文件与刷新

- **状态文件**：`backend/strategy_state.json`（可由环境变量 `DASHBOARD_STATE_PATH` 覆盖）。
- **写入时机**：QMT 策略每根 K 线 `handlebar` 结束时调用 `write_state_to_dashboard`。
- **前端刷新**：页面每 10 秒请求上述 API 一次，获取最新状态。
